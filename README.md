# 📝 RisuMemo

RisuAI(플러그인 API 3.0)에서 쓰는 폴더형 메모장 플러그인입니다.

## 설치

1. [`RisuMemo.js`](https://raw.githubusercontent.com/EXena1722/RisuMemo/main/RisuMemo.js)를 내려받습니다. ([릴리즈](https://github.com/EXena1722/RisuMemo/releases)에서 버전별로 받을 수도 있습니다.)
2. RisuAI → 설정 → 플러그인 → 플러그인 불러오기로 파일을 선택합니다.
3. "메인 화면 접근" 권한을 물으면 허락해 주세요. 떠 있는 📝 버튼과 단축키에 필요하고,
   Chrome 계열 브라우저(Chrome, Edge, 비발디 등)에서는 메모장을 다시 열 때 창이 제대로 보이게 하는 데도 필요합니다.
   거부해도 설정 메뉴의 📝 RisuMemo로 메모장을 열 수는 있지만, 두 번째로 열 때부터 배경만 어두워지고 창이 안 보일 수 있습니다.
   (이때는 브라우저 창 크기를 바꾸면 보입니다.)

## ⚠️ 3.x에서 업데이트하는 경우

3.x는 메모를 플러그인 설정값에 저장했고, **RisuAI는 플러그인을 업데이트할 때 설정값을 초기화합니다.**
업데이트하기 전에 반드시 백업해 주세요.

1. 3.x 메모장에서 💾 → **브라우저에 백업** (또는 파일로 내보내기)
2. 4.0으로 업데이트
3. 메모장을 처음 열면 브라우저 백업을 불러올지 묻습니다 → 확인
   (파일로 내보냈다면 💾 → 파일로 불러오기)

4.0부터는 메모를 플러그인 전용 저장소에 보관하므로 이후 업데이트에서는 메모가 지워지지 않습니다.

## 여는 방법

| 방법 | 동작 |
|---|---|
| 떠 있는 📝 버튼 | 메모장 열기/닫기. 위쪽 회색 바를 잡고 끌어서 옮길 수 있습니다. |
| 채팅 메뉴 → 📝 RisuMemo | 떠 있는 버튼 표시/숨김 |
| 설정 메뉴 → 📝 RisuMemo | 메모장 열기 |
| Ctrl+Shift+Z+X | 메모장 열기/닫기 (🎨 메뉴에서 켜야 동작, 기본 꺼짐) |

메모장이 열려 있는 동안에는 뒤쪽 RisuAI 화면을 조작할 수 없습니다. 바깥 클릭이나 Esc로 닫을 수 있습니다.

## 주요 기능

- 폴더와 메모 탭, 드래그로 순서 변경, 탭을 폴더 위로 끌어 다른 폴더로 옮기기
- 찾기/바꾸기, 전체 메모 목록, Ctrl+S 저장
- 테마 2종 (Navy / Ivory)
- 백업: 클립보드, 브라우저(이 기기), 파일 내보내기/불러오기, MemoPlus 메모 가져오기

## 데이터 저장 위치

- 메모: RisuAI 플러그인 저장소 (세이브 파일에 포함, 기기 간 동기화)
- 창 위치·테마 등 화면 설정: 이 기기의 브라우저 저장소

플러그인을 삭제해도 메모 데이터는 세이브 파일에 남습니다. 완전히 지우려면 삭제하기 전에 💾 → **메모장 완전 초기화**를 해 주세요.

## 문제 해결

창이나 버튼 위치가 꼬였으면 🎨 → **창·버튼 위치 초기화**를 누르세요.
메모장을 열 수 없는 상황이라면 플러그인 설정의 `risumemo_ui_reset` 칸에 `reset`을 입력하고 새로고침하면 됩니다.
